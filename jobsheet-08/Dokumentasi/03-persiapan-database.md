# 3. Persiapan Database

1. Pastikan PostgreSQL aktif.
2. Buat database `esport_championship`.
3. Jalankan `sql/01_divisi_anggota.sql`.
4. Pastikan tabel `divisi` dan `anggota` muncul.
5. Sesuaikan username/password PostgreSQL di `includes/koneksi.php`.

Contoh pembuatan database:

```sql
CREATE DATABASE esport_championship;
```

Setelah database tersedia, jalankan DDL pada file SQL project.
